## 3. 确定性检查（黄金比对）

应用内建 `DETERM_CHECK`：同一张输入图**连续推理两次**，逐字节比较两次的输出缓冲区。

| 图片 | `run1` | `run2` | `identical` |
|---|---|---|---|
| dog.jpg | -7891502 | -7891502 | **1** ✅ |
| person.jpg | -7645145 | -7645145 | **1** ✅ |
| eagle.jpg | -8543253 | -8543253 | **1** ✅ |
| giraffe.jpg | -8240461 | -8240461 | **1** ✅ |
| horses.jpg | -7603809 | -7603809 | **1** ✅ |
| kite.jpg | -8183441 | -8183441 | **1** ✅ |
| bike.jpg | -7761171 | -7761171 | **1** ✅ |
| blackdog.jpg | -7218229 | -7218229 | **1** ✅ |

**为什么这条自检比"检出正确"更有价值**：它能同时发现两类**外在现象完全相同**的故障 ——

| 故障 | 现象 | 这条自检如何区分 |
|---|---|---|
| 2x 时钟比例错误 | 每次输出都不同，且都有大量荒谬类别 | `identical=0`，且**第一次就错** |
| DPU 输出覆盖了输入缓冲区 | 每次输出都不同 | `identical=0`，但**第一次一定正确** |

而正常情况下（如上表）两次完全相同，且与历史验收记录**逐字节一致**。

## 4. DPU 输出张量的旁证数据

每张图都记录了 DPU 两个输出层（`RAWOUT`）的统计量，可作为结果可复现性的旁证。
以 `dog.jpg` 为例：

```
IN_SCALE: 128  IN_MIN: 0  IN_MAX: 127  IN_SUM: 33129232
OUT0: scale=0.25 ch=255 13x13 size=43095 min=-82  max=24  sum=-1219229
OUT1: scale=0.25 ch=255 26x26 size=172380 min=-127 max=32  sum=-6672273
```

| 图片 | `IN_SUM` | `OUT0 sum` | `OUT1 sum` |
|---|---|---|---|
| dog.jpg | 33129232 | -1219229 | -6672273 |
| person.jpg | 38730196 | -1130197 | -6514948 |
| eagle.jpg | 24743103 | -1248467 | -7294786 |
| giraffe.jpg | 20757113 | -1215321 | -7025140 |
| horses.jpg | 33288214 | -1124244 | -6479565 |
| kite.jpg | 45225912 | -1223613 | -6959828 |
| bike.jpg | 49524358 | -1197786 | -6563385 |
| blackdog.jpg | 34760222 | -1052021 | -6166208 |

#### 4.1 预处理正确性的证据

`IN_SCALE = 128`、`IN_MIN = 0`、`IN_MAX = 127` 说明输入量化正确。

本项目使用 **darknet 风格 letterbox**（保持长宽比，0.5 灰边填充）：

```
灰值 0.5 → 8 位 128 → 量化后 64     （板端日志: "input scale 128, grey 128 -> 64"）
量化公式: int8_t(int(v / 255 * scale))，负值 → 127（饱和）
```

**这一条必须强调**：早先的实现走的是"直接拉伸到 416×416"的路径
（`video_loop.cpp` 的 `fast_set_input`），它**与 letterbox 不等价**，
会导致**检测框位置系统性偏移**。当前交付版本使用 letterbox，
并在框还原时做了 letterbox 偏移校正。

## 5. 复现方法

板端：

```sh
# 前提：比特流已加载、PL 时钟已配置、dpu.ko 已 insmod、应用已启动
busybox devmem 0x40000000        # 应为 0x0D9C13F1（确认比特流生效）
echo ID=$(busybox devmem 0x40000000) SIG=$(busybox devmem 0x40f00000)
# 期望: ID=0x0D9C13F1  SIG=0x0C014450
```

然后对 8 张图逐张运行诊断程序，检查每张输出里的
`DETERM_CHECK: ... identical=1` 与 `BOXES: raw=N after_nms=M`。

原始输出见 [`raw/batch_fixed_results.log`](raw/batch_fixed_results.log)。
