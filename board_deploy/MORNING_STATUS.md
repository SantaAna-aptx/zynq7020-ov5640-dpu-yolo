# 相机排障最终状态（06:20 更新）

## ✅ 已验证正常的（本轮全部核清）
1. **XDC 引脚约束与硬件手册 J5 表逐脚一致**（600dpi 高清渲染核对 14 脚全对）：
   - J5-2=SDA/F20(2.2K上拉)、J5-3=SCL/F19(2.2K上拉)、J5-4=HREF/B20、J5-5=VSYNC/C20
   - J5-6=XCLK/D20(49.9Ω 串阻)、J5-7=PCLK/D19(49.9Ω 串阻)
   - 数据脚: J5-9=F16(D7)、8=F17(D6)、11=E18(D5)、10=E19(D4)、13=E17(D3)、12=D18(D2)、15=B19(D1)、14=A20(D0)
2. **时序通路活着**：VDMA 每次都能完成 720 行帧传输（PCLK/HREF 在翻转）
3. **软件全链路**：断电重启→引导→配网→比特流→驱动→抓帧（90 秒全自动）
4. **决定性实验**：黑暗/手电照/手掌盖 三种状态抓帧 **md5 逐位相同** → 传感器对光无响应，数据口三态浮空

## 结论
**I2C 配置没有成功生效**（OV5640 复位后数据口默认三态，需 SCCB 配置才驱动输出；
配置由 PL RTL 在比特流加载时自动执行一次，write-only 无 ACK 校验，失败无任何报错）。

I2C 失败的可能原因（按概率排序）：
1. 模块不是 OV5640（背面丝印待确认！）
2. 排线/座子接触（已重插一次未解决，但需确认插到底+方向）
3. SCCB 时序兼容性（SCCB 与标准 I2C 在 ACK 位上有差异，write-only 设计掩盖了 NACK）
