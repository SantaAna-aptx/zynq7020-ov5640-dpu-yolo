# 相机排查清单 v4（2026-09-29 纯软件搜查·根因确认版）

## 🎯 根因已确认（原理图实锤）
**模组上 CMOS_PWDN 的下拉电阻 R3 4.7K 在原理图里是灰色断开（DNP 不装）**
→ PWDN 悬空 = OV5640 硬件掉电（复位默认 0x3008=0x42，bit6=PowerDown）
→ XCLK 无响应、SCCB 无应答、PCLK 无输出、数据全无 → 全系统沉默
→ 这解释了"按原理图直插正确接线仍然无图"——原理图本身就留了这个坑

## ✅ 修复 = 一根线
**模组丝印 PWDN（排针 20 脚）→ 板子 GND（2 脚或 17 脚）**
其余 1~16 脚按丝印对插不变；18/19（STROBE/FREX）悬空；RST 本模组不引出

## 为什么教程摄像头能"直插"而我们的要按丝印接线（重要结论）
- 教程（P1摄像头.pdf 第9页照片）的米联客摄像头是 **公针 2×10 直插版**：模块第 17 脚=地、
  PWDN 在模块内部已下拉（VIP 原理图证实），直插即工作
- 我们手头是 CrazyBingo **OV5640 Core 8Bit 母座版**：第 17/18 脚=RST/PWDN、连接器为母座，
  物理上就插不进 CEP（也是母座），且直插会把 RST 接到板子的 GND 上锁死复位
- 因此必须杜邦线按丝印接线。**约束本身没有错**：把丝印表和 CEP1 表逐位对齐，与直插对应关系
  完全一致（这正是 XDC 的来源）

### ⚠️ 最后 4 根线的陷阱（不要按位置对插，按丝印接！）
我们的模块丝印行序：…D1 D0 / **RST PWDN** / **FREX STRO**
- **模块 PWDN → 必须接 GND**（板 J5-2 或 J5-17 都行）。PWDN 悬空传感器可能一直睡眠！
- **模块 RST → 悬空**（模块内部上拉）。**绝不能接到 GND**，否则传感器永远复位、I2C 无应答！
- 模块 FREX / STRO → 悬空
- 板 J5-17 (GND) → 接到模块丝印为 **GND** 的脚；如果手头线不够，可以不接（J5-2 已提供地）
- SCCB 地址 0x78 已由 VIP 模块原理图确认（Write 0x78 / Read 0x79），RTL 修复无误

### 数据位语义（待抓帧后验证的最后一个悬念）
VIP 模块原理图：排针数据脚 = 传感器 **D[9:2]**（8-bit 模式的字节位），即丝印 Dx = 字节 bit x
（丝印 D7=传感器D9 … 丝印 D0=传感器D2）。若抓出的帧直方图只有 6-bit 动态范围（高位恒零），
说明丝印是传感器 pads D0-D7 → RTL 改为 pixel = data>>2（6-bit 色彩降级，可先跑通）。
